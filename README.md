# 🎉 Bhirthdayhoney 🎂

Proyek website interaktif yang dibuat khusus sebagai hadiah spesial untuk merayakan hari ulang tahun.

## 🎵 Fitur Utama
* **Halaman Ucapan Spesial:** Desain web interaktif untuk menampilkan pesan ulang tahun yang menarik.
* **Latar Belakang Musik:** Pemutar audio otomatis menggunakan file musik pilihan (`blue.mp3`) untuk membangun suasana romantis atau ceria.

## 📁 Struktur File
* `index.html` - Halaman web utama (pastikan untuk mengubah nama file `index (1).html` Anda menjadi `index.html` agar sistem dapat membacanya).
* `blue.mp3` - File audio latar belakang.
* `README.md` - Dokumentasi dan penjelasan proyek ini.

## 🚀 Cara Menjalankan Website
1. Buka repositori ini di GitHub.
2. Aktifkan fitur **GitHub Pages** melalui menu *Settings* -> *Pages*.
3. Pilih branch `main` lalu klik *Save*.
4. Tunggu 1-2 menit, dan website siap diakses secara online melalui tautan yang diberikan oleh GitHub!
